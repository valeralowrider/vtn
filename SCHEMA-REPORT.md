# Проверка микроразметки — 15.10.2026

Источник истины для сайта — `src/lib/schema.ts`; JSON-LD выводится в исходном HTML. Файл `generated-schema.json` — пример готовых фрагментов, не подключаемый повторно к страницам.

| Страницы | Тип | Результат локальной проверки |
| --- | --- | --- |
| Главная | Organization, WebSite, три Service | Корректный JSON; ссылки услуг ведут на существующие страницы |
| Три страницы услуг | Service | Корректный JSON; название и описание совпадают с видимым текстом |
| Документы | Organization | Корректный JSON; реквизиты представлены на странице |
| О компании, контакты | Без дополнительной схемы | Лишние неподтверждённые типы не добавлены |

Логотип Organization заменён на контрастный значок 512 × 512 px. Схемы услуг связываются с организацией через единый `@id`. Часы работы, рейтинги, отзывы и гарантии выпуска не добавлялись: подтверждённых данных нет.

Локальная проверка: все семь страниц отдают HTTP 200, JSON-LD разбирается как JSON, canonical и Open Graph относятся к текущей странице. `robots.txt`, `sitemap.xml`, `llms.txt` отдают HTTP 200. Проверка в Google Rich Results Test и индексация после публикации ещё не выполнялись; наличие Schema.org не гарантирует расширенный результат поиска.

Перед релизом: подтвердить основной домен `https://vtntrans.ru`, сверить публичные реквизиты и контакты, проверить живые URL и разметку после публикации.
